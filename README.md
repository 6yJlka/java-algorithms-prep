# Java Algorithms Preparation

Репозиторий для подготовки к алгоритмическим секциям и онлайн-отборам на позиции Java Developer.

## Цели

- повторить основные алгоритмы и структуры данных;
- научиться определять временную и пространственную сложность;
- решать задачи на Java;
- писать тесты для решений;
- отслеживать прогресс подготовки.

## Стек

- Java 21
- Gradle
- JUnit 5

## Структура

- `src/main/java` — решения задач;
- `src/test/java` — тесты;
- `docs/theory` — теория;
- `docs/progress` — журнал решенных задач;
- `docs/templates` — шаблоны разбора задач.

## Темы

- Complexity
- Arrays and Strings
- HashMap and HashSet
- Two Pointers
- Sliding Window
- Binary Search
- Stack and Queue
- Linked Lists
- Trees
- Graphs
- Heap
- Backtracking
- Dynamic Programming
