# Java Algorithms Preparation

Репозиторий для подготовки к алгоритмическим секциям, онлайн-отборам и техническим интервью на позиции Java Developer.

Основной подход — изучение типовых паттернов решения алгоритмических задач и закрепление каждого паттерна на задачах с LeetCode.

## Цели

- изучить основные паттерны решения алгоритмических задач;
- научиться распознавать подходящий паттерн по условию;
- повторить структуры данных и алгоритмы;
- уверенно оценивать временную и пространственную сложность;
- решать задачи на Java;
- подготовиться к онлайн-отборам в крупные компании;
- отслеживать прогресс и повторять сложные задачи.

## Подход к подготовке

Для каждого паттерна используется следующий порядок:

1. Разобрать идею паттерна.
2. Определить признаки его применения.
3. Изучить базовые шаблоны реализации на Java.
4. Рассмотреть небольшой учебный пример.
5. Решить подобранные задачи на LeetCode.
6. После получения `Accepted` сохранить решение в репозиторий.
7. Записать результат и ошибки в журнал прогресса.
8. Повторно решить задачу через несколько дней без подсказок.

Проверка решений выполняется тестами на платформе LeetCode. Отдельные локальные тесты для задач не создаются.
