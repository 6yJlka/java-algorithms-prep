# Complexity Analysis

## Что такое алгоритмическая сложность

Алгоритмическая сложность показывает, как изменяется количество операций или используемой памяти при увеличении размера входных данных.

Обычно размер входных данных обозначается как `n`.

## Временная сложность

Временная сложность оценивает рост количества операций алгоритма.

Основные классы сложности:

| Сложность | Название | Пример |
|---|---|---|
| `O(1)` | Константная | Получение элемента массива по индексу |
| `O(log n)` | Логарифмическая | Бинарный поиск |
| `O(n)` | Линейная | Один проход по массиву |
| `O(n log n)` | Линейно-логарифмическая | Эффективная сортировка |
| `O(n²)` | Квадратичная | Два вложенных прохода |
| `O(2ⁿ)` | Экспоненциальная | Перебор всех подмножеств |
| `O(n!)` | Факториальная | Перебор всех перестановок |

## Правила оценки

### Константы отбрасываются

```java
for (int number : numbers) {
    System.out.println(number);
}

for (int number : numbers) {
    System.out.println(number);
}
```

Два последовательных прохода дают:

```text
O(n) + O(n) = O(2n) = O(n)
```

### Учитывается наиболее быстро растущая часть

```text
O(n² + n + 10) = O(n²)
```

### Вложенные циклы обычно перемножаются

```java
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        // операция
    }
}
```

Сложность:

```text
O(n²)
```

### Последовательные независимые блоки складываются

```java
for (int number : first) {
    // O(n)
}

for (int number : second) {
    // O(m)
}
```

Сложность:

```text
O(n + m)
```

Нельзя автоматически заменять её на `O(n)`, потому что размеры массивов могут быть разными.

## Пространственная сложность

Пространственная сложность показывает, сколько дополнительной памяти использует алгоритм.

```java
int sum = 0;
```

Дополнительная память:

```text
O(1)
```

```java
Set<Integer> seen = new HashSet<>();

for (int number : numbers) {
    seen.add(number);
}
```

В худшем случае множество хранит все элементы:

```text
O(n)
```

Входной массив обычно не считается дополнительной памятью, поскольку он уже передан алгоритму.

## Амортизированная сложность

Добавление элемента в `ArrayList` обычно выполняется за `O(1)`.

Иногда внутренний массив заполняется, после чего создаётся новый массив большего размера и элементы копируются. Такая отдельная операция стоит `O(n)`.

Однако расширение происходит не при каждом добавлении, поэтому средняя стоимость последовательности добавлений считается амортизированной:

```text
O(1)
```

## Что указывать для решения

Для каждого решения необходимо определять:

- временную сложность;
- дополнительную пространственную сложность;
- худший или средний случай, если это существенно.

## Главный вывод

Big O описывает не точное время работы программы, а скорость роста количества операций при увеличении входных данных.
