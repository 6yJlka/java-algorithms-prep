## Как использовать каталог

1. Перед задачей изучить соответствующий файл в `docs/patterns`
2. Сначала решать самостоятельно
3. Не открывать готовое решение до полноценной попытки
4. После Accepted сохранить решение в репозитории
5. Обновить `docs/progress/leetcode-tracker.md`
6. В трекере честно указать степень самостоятельности
7. В roadmap не хранить даты и подробные статусы
8. Новые задачи добавлять в соответствующий паттерн
9. Не дублировать каталоги задач в теоретических файлах
